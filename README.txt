راهنمای بوتیک GHΛZ
==================
این نسخه یک فروشگاه استاتیک HTML/CSS/JavaScript است و به Node.js یا سرور اختصاصی نیاز ندارد.
برای بارگذاری فایل JSON و اجرای پنل مدیریت، سایت را از طریق هاست استاتیک و HTTPS باز کنید (باز کردن مستقیم با file:// مناسب نیست).

ساختار:
- index.html: فروشگاه مشتری
- admin.html: پنل مدیریت
- css/style.css: طراحی و انیمیشن‌ها
- js/app.js: دسته‌بندی، جستجو، سبد خرید و سفارش واتساپی
- js/admin.js: مدیریت محصولات و تنظیمات
- data/shop.json: داده‌های فروشگاه

انتشار روی GitHub Pages:
1. تمام محتویات پوشه mobile-shop را در Repository قرار دهید.
2. در Settings > Pages، انتشار از شاخه اصلی و پوشه root را فعال کنید.
3. پس از انتشار، آدرس GitHub Pages را باز کنید.
4. پنل مدیریت در مسیر /admin.html قرار دارد.

مدیریت محصولات:
1. بار اول admin.html را باز کنید. اگر shop.json رمز مدیر ندارد، رمز اولیه حداقل ۸ کاراکتری بسازید؛ در نسخه فعلی یک هش اولیه از قبل تنظیم شده است.
2. با رمز فعلی وارد شوید.
3. محصول، دسته‌بندی، قیمت، موجودی، لینک عکس HTTPS، سایز و رنگ را ثبت کنید.
4. پس از تغییر اطلاعات، «ذخیره و دانلود shop.json» را بزنید و فایل دانلودشده را در پوشه data جایگزین کنید و دوباره روی هاست منتشر کنید.

دسته‌بندی‌ها: زنانه، مردانه، بچگانه، کفش، کیف و اکسسوری.
سفارش‌ها از طریق واتساپ ارسال می‌شوند. برای نمایش تصویر محصول، لینک مستقیم HTTPS تصویر را در پنل وارد کنید.

محدودیت امنیتی مهم:
این پنل یک پنل استاتیک سمت مرورگر است؛ رمز و اطلاعات داخل فایل JSON عمومی سایت قابل دریافت‌اند و پنل احراز هویت امن سمت سرور ندارد. برای فروشگاه واقعی، پوشه admin.html و فایل داده‌ها را با کنترل دسترسی هاست محافظت کنید یا از بک‌اند امن استفاده کنید. همچنین سفارش و موجودی در پایگاه داده ذخیره نمی‌شود.
